# bmkaraduman.github.io

Semavi uygulamasının yayınlanan sayfaları.

- `index.html` — ana sayfa / destek (App Store **Destek URL'si**)
- `gizlilik.html` — gizlilik politikası, Türkçe (App Store **Gizlilik Politikası URL'si**)
- `privacy.html` — gizlilik politikası, İngilizce
- `privacy-policy-en.txt` — aynı metnin düz sürümü
- `impressum.html` — § 5 DDG uyarınca sağlayıcı bilgileri
- `app-ads.txt` — AdMob doğrulaması (kök dizinde olmak zorunda)

Yayınlamadan önce `impressum.html` içindeki `VERTRETUNGSBERECHTIGTE_PERSON` ve
`UST_ID_ODER_HINWEIS` alanları doldurulmalı.
